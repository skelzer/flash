# Flash

A self-hosted, Anki-style spaced repetition app for learning German — built as a single
Cloudflare Worker with a D1 database and a vanilla-JS installable PWA front end.

Live at [flash.luquematte.com](https://flash.luquematte.com).

## Features

- **SM-2 scheduler** with learning/relearning steps, ease adjustment and interval fuzz
  ([`src/scheduler.js`](src/scheduler.js)) — a pure function, so the four answer buttons can
  preview their own next intervals.
- **Decks and cards** with full CRUD, plus per-deck and global review statistics.
- **Anki `.apkg` import** parsed entirely in the browser (jszip + sql.js + fzstd), so
  decks never round-trip through the server.
- **Accounts** via Google sign-in or username/password, with server-side sessions.
- **Offline-capable PWA** — service worker, web manifest, generated icons.

## Stack

[Hono](https://hono.dev) on Cloudflare Workers · D1 (SQLite) · esbuild · no front-end framework.

## Running it yourself

```bash
npm install
npx wrangler d1 create flash-db     # then put the returned id in wrangler.jsonc
npm run db:migrate:local
npm run dev
```

Create a `.dev.vars` file for local secrets:

```
APP_PASSPHRASE=<anything, gates registration if set>
GOOGLE_CLIENT_ID=<optional; Google sign-in is hidden when empty>
```

Deploy with `npm run deploy`, and apply migrations to the live database with
`npm run db:migrate:remote`.

## Layout

| Path | What it is |
| --- | --- |
| `src/worker.js` | API routes, auth, session handling |
| `src/scheduler.js` | SM-2 scheduling logic |
| `src/importer.js` | `.apkg` parser, bundled to `public/importer.js` |
| `public/` | Front end (`app.js`, `style.css`, service worker) |
| `migrations/` | D1 schema migrations |
| `scripts/` | Build and icon generation |

`public/importer.js` and `public/sql-wasm-browser.wasm` are build outputs — they are
generated by `npm run build` and not checked in.
